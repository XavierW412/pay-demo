# 运营后台首版实施计划

**目标：** 建立受保护的运营账号、真实交易列表、交易详情、审计和限定员工的异常操作。

**设计：** [运营后台首版设计](../../architecture/operations/operations-console.md)。

**技术：** Spring Security 服务端会话、PostgreSQL、React、TanStack Query。

## 工作项

- [x] 引入 Spring Security，添加账号、邀请、备注、审计迁移；本地和生产分别从环境变量引导所有者和员工管理员。
- [x] 实现登录、登出、CSRF、当前账号、邀请注册；后台权限由服务端按角色校验，所有者只读。
- [x] 实现真实交易列表、详情、退款记录与审计读取；结算数据源未接入时明确显示待接入。
- [x] 实现员工核实 Airwallex、重试失败通知、追加备注，保留操作人、对象、时间和结果；拒绝所有者写操作。
- [x] 建立运营前端登录、列表、详情、核查和审计页面；员工操作有确认和错误反馈。
- [ ] 用本地账号分别核对员工操作和所有者写入拒绝，并完成人工页面验收。
